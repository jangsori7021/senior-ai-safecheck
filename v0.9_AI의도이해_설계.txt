v0.9 음성 → 의도 이해 → 행동 연결

현재 구현:
- 실제 브라우저 한국어 음성인식
- 들은 문장을 그대로 명령으로 실행하지 않고 재확인
- 사기/안전, 맛집, 병원·약국, 일정, 요리, 가족 등 기본 의도 분류
- 의도에 따라 기존 앱 기능으로 자동 라우팅
- 틀린 경우 전체 재입력 대신 부분 수정 UX 유지

중요:
현재 v0.9의 의도분류는 API 키 없이 동작하는 로컬 규칙 기반 프로토타입.
최종 서비스에서는 AI Provider 계층으로 교체하여
문맥, 사투리, 불완전 문장, 발음 오류, 이전 대화까지 고려해 이해하도록 한다.

최종 음성 파이프라인 후보:
마이크 → STT → 후보 문장/신뢰도 → 문맥 보정 → 의도/슬롯 추출
→ 위험도 판단 → 사용자 재확인(필요 시) → 기능 실행 → TTS 쉬운 음성 안내

실행 안전:
송금/결제/예약 확정/개인정보 공유 등 중요한 행동은 별도 확인을 거친다.
