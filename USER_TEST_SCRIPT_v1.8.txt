v1.8 사용자 테스트 진행안

원칙: 먼저 설명하지 않는다. 사용자가 어디에서 막히는지 관찰한다.

시니어 시작 멘트:
“이 앱을 처음 받았다고 생각하시고, 이 수상한 문자가 괜찮은지 한번 확인해 보세요.”

관찰 후 질문:
1. 방금 앱이 뭐라고 알려줬다고 이해하셨어요?
2. 지금 무엇을 해야 한다고 생각하세요?
3. 어려웠던 부분이 어디였나요?
4. 다음에 비슷한 일이 생기면 이 앱을 다시 열 것 같으세요?
5. 이 앱이 또 어떤 순간에 있으면 좋겠나요?

자녀/가족 질문:
1. 부모님께 이 앱을 보내드릴 이유가 있나요?
2. 어떤 기능이 있어야 안심 때문에 비용을 낼 수 있나요?
3. 반대로 어떤 기능은 감시받는 느낌이라 싫을 것 같나요?
4. 무료와 유료의 경계가 어디면 자연스럽다고 느끼나요?
5. 실제로 부모님께 지금 보내겠습니까?

금지:
- “좋죠?” 같은 유도 질문
- 기능을 먼저 설명한 뒤 사용성 평가
- 호감 표현을 구매의향으로 간주
