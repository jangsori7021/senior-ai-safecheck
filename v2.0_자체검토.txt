v2.0 자체검토

이번 결정은 버전 숫자보다 제품 구조의 전환을 의미한다.

기존:
사용자가 '안전/설명/화면도움' 기능을 선택 → 입력 → 결과.

v2.0:
사용자는 기능을 선택하지 않는다.
그냥 사진을 보여주거나 말한다.
AI가 상황을 분류하고 한 줄 결론, 이유, 지금 할 일을 제시한다.

핵심 UX:
ONE INPUT → ONE ANSWER → ONE NEXT ACTION

경쟁력 가설:
범용 AI보다 모델 자체가 더 똑똑해서가 아니라,
시니어가 프롬프트를 만들지 않아도 되고,
실패/불확실/고위험 상황에서 안전하게 행동하며,
가족/공식 확인/다음 행동까지 연결되는 오케스트레이션에서 차별화한다.

Scope Lock:
이 루프가 실제 AI로 작동하고 파일럿 검증되기 전까지
맛집/취미/커뮤니티 등 새로운 소비자 기능 카테고리를 추가하지 않는다.

공통 앱 시스템 승격 후보:
One Input UX
AI Auto-Routing
Scope Lock
One Answer / Max-3 Actions Renderer
