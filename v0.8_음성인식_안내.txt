v0.8 실제 브라우저 음성인식 연결

작동 흐름:
말하기 시작 → 마이크 권한 → 한국어 음성인식 → 실시간 텍스트 표시
→ '맞아요 / 다시 말하기 / 한 부분만 고치기'

테스트 권장:
- 데스크톱/안드로이드 Chrome 또는 Edge
- 브라우저에서 마이크 권한 허용
- 로컬 파일(file://)에서 권한이 제한되는 브라우저가 있을 수 있으므로,
  실제 배포에서는 HTTPS 웹주소에서 테스트하는 것이 권장됨.

중요:
현재 v0.8의 음성인식은 브라우저 제공 기능을 사용한다.
최종 제품에서는 브라우저별 편차를 줄이고 정확도/문맥보정/비용을 비교해
서버 기반 STT 및 실시간 AI 음성 모델을 교체 가능한 Provider 구조로 연결할 계획이다.
