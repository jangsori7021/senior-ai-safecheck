시니어 AI 생활 플랫폼 v2.9 — Render 배포

준비된 구조:
- Render Web Service 1개
- FastAPI + AI API + 시니어 웹 화면을 같은 HTTPS 주소에서 제공
- render.yaml Blueprint
- Dockerfile
- API 키는 Render 비밀 환경변수에서만 입력
- 기본 파일럿 모델: gpt-5.6-terra (환경변수로 교체 가능)

사용자가 실제로 해야 하는 최소 3단계
1. 이 프로젝트를 GitHub 저장소에 올린다.
2. Render에서 New Blueprint를 선택하고 그 GitHub 저장소를 연결한다.
3. Render가 OPENAI_API_KEY를 묻는 화면에서 서버용 API 키를 입력하고 배포한다.

배포가 끝나면:
- https://...onrender.com/  → 앱 화면
- https://...onrender.com/health → 서버 상태
- 사진 촬영 → 같은 주소의 /api/v1/analyze-image로 실제 분석

중요:
API 키를 HTML/소스코드/GitHub에 넣지 않는다.
채팅에도 API 키를 보내지 않는다.
