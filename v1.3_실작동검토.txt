v1.3 실제 작동 개발

이번에 REAL로 올린 부분:
- 모바일 카메라 호출용 이미지 입력
- 갤러리 이미지 선택
- 파일 타입/12MB 크기 검사
- 선택 이미지 로컬 미리보기
- 선택한 사진을 안전/쉬운설명/화면도움 중 하나로 분기

아직 REAL이 아닌 부분:
- 이미지의 실제 의미 분석
- OCR/비전 AI
- 사기/위험 판정
- 화면 요소 위치 파악
- 서버 업로드 및 개인정보 처리

중요한 자체판정:
가짜 AI 결과를 만들어 '작동한다'고 보이지 않도록 했다.
v1.3은 이미지 입력 계층만 REAL이며 분석은 명시적으로 미연결 상태다.

다음 기술 블록:
Image Input → AI Provider → Structured Analysis JSON → Safety Gate
→ Senior-friendly Renderer → Next Action Connector

출시 전 필수:
HTTPS, 권한 UX, 이미지 압축/EXIF 정책, 보관기간/삭제,
민감정보 처리, 오류/타임아웃, 비용 제한, 관측성.
