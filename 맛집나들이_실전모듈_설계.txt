v0.5 맛집·나들이 실전 모듈

사용 흐름
홈 → 오늘 뭐하지? → 맛집·나들이 → 내 주변 맛집 → 음성/큰 선택 버튼
→ AI가 조건 재확인 → 추천 3곳 → 상세 → 길안내/전화/예약

실서비스 연결 계획
1. 위치 권한: 사용자 동의 후 현재 위치
2. 장소 데이터: 공급자 커넥터를 통해 주변 음식점 검색
3. AI: 거리/사용자 요청/취향을 이해해 후보를 소수로 압축하고 쉬운 이유 설명
4. 행동: 지도 길찾기, 전화, 예약 파트너 연결
5. 수익: 예약/쿠폰/제휴 거래가 실제 완료된 경우 계약에 따른 수수료
6. 측정: restaurant_search, recommendation_shown, detail_view, route_click,
   call_click, booking_click, booking_complete, commission_value
7. 신뢰 원칙: 광고/제휴는 명확히 표시. 제휴 여부가 추천 품질보다 앞서지 않음.

현재 v0.5는 API 키가 없는 클릭형 UX 프로토타입이므로 실제 업체/실시간 영업정보를 표시하지 않음.
