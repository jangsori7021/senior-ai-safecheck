v2.6 P0 자체검토

이번 버전에서 실제로 전진한 부분:
프런트 화면과 기존 FastAPI 백엔드 계약을 연결했다.
사진 선택 → API 전송 → 실제 구조화 응답 → 결과 렌더링 코드가 하나의 흐름이 됐다.
20초 timeout과 서버 오류를 시니어용 복구 문장으로 처리한다.
서버가 없거나 AI가 설정되지 않았을 때 가짜 결과를 보여주지 않는다.

남은 Hard Blocker:
1. 외부 HTTPS 환경에 백엔드 배포
2. 서버측 유효 AI 자격증명/멀티모달 모델 설정
3. 실제 휴대폰 엔드투엔드 검증
4. 개인정보 동의/보관정책의 실제 구현
5. 실제 테스트 이미지로 false-safe 측정

판정:
코드 레벨의 end-to-end 연결은 구현됨.
라이브 end-to-end 성공은 아직 검증되지 않았으므로 REAL이라고 표시하지 않는다.
